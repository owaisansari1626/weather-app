# Aura Weather App

A beautiful, premium weather application built with Vanilla HTML, CSS, and JavaScript. 

It features dynamic glassmorphism aesthetics, dark/light modes, user-location-based weather detection, and a 5-day forecast. Best of all, it's powered entirely by the completely free [Open-Meteo API](https://open-meteo.com/), meaning **zero setup is required!**

## Features
- **Current Weather Info**: Instant temperature, humidity, wind speed, and "feels like" metrics.
- **5-Day Forecast**: Easily scrollable view of the upcoming weather.
- **Location Auto-Detection**: Get your local weather instantly via your browser's Geolocation API.
- **Search by City**: Type any city in the world to get accurate weather results.
- **Dark & Light Mode**: Seamlessly switch themes, and it automatically saves your preference!
- **Premium UI**: Crafted meticulously with custom gradients and glass panel styling.

## 🚀 Setting Up the Project

### 1. Run the App
Since this is a lightweight Vanilla JS project and uses a 100% free open-source weather API, there are no API keys, build steps, or installations required!

You can run the app simply by opening `index.html` in any modern browser:
- **Option A**: Double click on `index.html`.
- **Option B (Recommended for best experience)**: Use a local development server like VSCode's "Live Server" extension to serve the files seamlessly.

## Directory Structure
- `index.html` - The core structure of the web app.
- `styles.css` - Contains the premium glassmorphism styles and color variables.
- `app.js` - Handles all the dynamic state logic, Open-Meteo API fetching, and UI rendering.

Built cleanly without any heavy dependencies. Enjoy your brand new premium weather app!
